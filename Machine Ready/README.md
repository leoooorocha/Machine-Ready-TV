# Machine Ready TV

A minimalist, high-resolution custom Home theme designed for the ultimate big-screen gaming experience (also, the Star of this project).

## 🌟 Features

- **Fullscreen Hero:** Beautiful, immersive game artwork that takes center stage.
- **Custom Typography:** Clean and modern look featuring the **Quicksand** font (by Google Fonts).
- **Centered Carousel:** Perfectly balanced layout for effortless browsing.
- **Dynamic Carousel:** Smooth, responsive transitions tailored for TV resolutions.
- **Switch Mode:** A dedicated layout variant designed specifically to pair with **Square Capsules** from SteamGridDB.
